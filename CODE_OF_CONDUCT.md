# Code of Conduct

This project is maintained in spare time. To keep it a friendly place:

- Be respectful and constructive. Critique code and ideas, not people.
- No harassment, insults, discrimination or personal attacks of any kind.
- Do not post anyone's private data: tokens, keys, phone numbers, addresses, private messages.
- Stay on topic: setup questions, bugs and improvements for Instagram Manager.

Content that breaks these rules can be edited, hidden or removed, and repeat offenders can be blocked from the repository.
Report problems privately through GitHub: **Security → Report a vulnerability** on this repository (it is private and reaches the maintainer only).

Inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
