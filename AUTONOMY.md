# MyBrand — мандат автономного управления

Дата: 2026-10-28. Основание: владелец поручил самостоятельное ведение, производство и публикацию контента без согласования каждого поста.

## Цель
Оригинальный медиапроект о кино и сериалах, позже авторские AI-видео. Органический рост, лояльная аудитория, затем монетизация через рекламу без гарантии результата.

## Полномочия
- Самостоятельно исследовать темы, готовить идеи, сценарии, изображения, обложки, подписи и материалы.
- **На текущем этапе показывать каждый материал владельцу до публикации.** Публиковать только после его явного решения по конкретному материалу. Позже переходить к автономной публикации только после отдельного согласия на смену режима.
- Собирать статистику, проводить эксперименты Viral Lab, корректировать стратегию и вести приватный архив.
- Дорабатывать собственный репозиторий и бесплатную инфраструктуру.

## Жёсткие ограничения
- Не использовать платные сервисы, не покупать рекламу или услуги без отдельного согласования.
- Не размещать чужие кинокадры, музыку и постеры без необходимой правовой оценки и прав. Оригинальные авторские материалы в приоритете.
- Не выдавать выдуманные факты или показатели за настоящие; факты о конкретных фильмах проверять.
- Нет накрутки, массфолловинга, массовых DM и спама. Никаких ложных спонсорских заявлений.
- @Aika_St в строгом стоп-листе: не взаимодействовать, не отвечать, не подписываться, не упоминать. Модерация комментариев по доступным разрешениям, блокировка аккаунта напрямую в Instagram владельцем.
- Вся автоматика ограничена собственным Instagram @MyBrand.
- Внутри чата не передавать пароли или токены.
- Изменение имени, BIO и аватара через официальный Instagram API недоступно. Эти изменения только в разрешённом, авторизованном браузере.
- Договоры с рекламодателями, платные операции, передача личных данных требуют отдельного решения владельца.

## Обучение на решениях владельца

По каждому материалу хранить решение владельца (одобрено / доработать / отклонено), причину, рубрику, формат, риски прав и источников, изменения и итоговые метрики. Это накопление правил и примеров, а **не самопроизвольное переобучение модели**. Перед отменой ручной проверки провести не менее 20 согласованных публикаций, несколько контрольных сравнений решений и отдельно согласовать активацию автономного режима. Даже после этого материалы с чужими кадрами, сомнительными правами, спойлерами, реальными неустановленными фактами и рекламой требуют отдельной проверки. Флаг режима хранится в `content/publishing-policy.json`; пока `review_each`.

## Технический gate публикации
Автопубликация допускается только после подтверждения разрешения instagram_business_content_publish, проверки исходных прав на каждый материал, разрешённого HTTPS медиахостинга, успешного теста публикации и надёжной защиты от дублей. До этого переменная IGM_ENABLE_PUBLISH остаётся false. Старый прямой вызов `publish-image` блокируется; для плановой публикации нужно подтверждение владельца, записанное в карточке.

## Статус
Instagram API чтения и запись дневных JSON-снимков в GitHub проверены. Google Drive содержит созданные папки; GitHub Actions -> Drive ещё не авторизован. Reels, новые Insights, автоматическая модерация и браузерные изменения профиля пока не подтверждены.

Мандат не означает, что ассистент уже непрерывно работает между диалогами. Фоновая работа — только фактически настроенные задания GitHub Actions или автоматизации.

## Аварийная остановка
Владелец может отключить публикации, задав IGM_ENABLE_PUBLISH=false в GitHub Actions Variables; это блокирует все задачи автопубликации.
